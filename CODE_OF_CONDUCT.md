# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive; critique work, not people; assume good faith; and keep
discussions about results grounded in the committed data and procedures. Harassment, personal
attacks, and discrimination of any kind are not tolerated.

Report unacceptable behaviour to the maintainer listed in `CITATION.cff`. Reports are handled
confidentially.
